# Vision Forte — веб-платформа

React-интерфейс и Express API для просмотра кассовых операций. SQLite хранит метаданные, очередь и результаты; видео находятся в файловом хранилище. Внешний сервер модели подключается по адресу и ключу. Веса в платформу не устанавливаются.

## Запуск

Из папки `platform` на Node.js 22.13+ (рекомендуется 24 LTS):

```sh
npm ci
npm run build
npm start
```

Интерфейс: `http://127.0.0.1:3001`. Первый запуск создаёт `.env` со случайным ключом платформы и правами `0600`. Локальный интерфейс получает HttpOnly/SameSite-сессию. Не копируйте пустое значение `FORTE_API_KEY` из примера: при ручной настройке нужен случайный ключ длиной не менее 24 символов.

Разработка: `npm run dev` (интерфейс на порту 5173 с прокси к API на 3001). Проверки: `npm run check`.

Для Electron и установщиков используйте [основной README](../README.md). Установленные приложения запускают изолированный сервис на свободном порту; конфигурация исходного проекта в них не копируется.

## Возможности

- Загрузка, просмотр MOV/MP4, HTTP Range и переход к таймкодам.
- Подключение собственного сервера модели по API и ключу с проверкой готовности.
- Очередь анализа; вердикты, описания, временные интервалы и кадры.
- ZIP-архивы: предупреждение о длительности, последовательная проверка и список ответов по каждому видео.
- Excel `.xlsx` с итогами по файлам, событиями и ошибками; промежуточная выгрузка также доступна.
- Сохранение записей, результатов и очереди, история архивов, повтор неудачных проверок.
- Нормативная база с поиском и ссылками на источники, интерактивные инструкции, пять тем.
- Явно помеченное синтетическое демо. Ошибки и недостаток данных не считаются отсутствием нарушений.

## Подключение модели

В интерфейсе откройте «Сервер модели» и укажите URL и ключ. Два протокола:

1. URL оканчивается на `/v1/analyze-video`: `GET /health` от корня сервера, `Authorization: Bearer …`; `POST` по полному URL с исходными байтами видео и `Content-Type: video/*`. Ответ содержит `result.prediction` и временные окна. Платформа проверяет результат и извлекает реальные кадры через FFmpeg.
2. Другой базовый URL, например `https://model.example/api/v1`: `GET /health`, `POST /analyze` с multipart-полем `file`, `GET /jobs/:id`; заголовок `X-API-Key`.

Ключ хранится только в памяти серверной части, не возвращается браузеру и не сохраняется в localStorage или SQLite. После перезапуска подключение требуется ввести заново. Передаются только видео и необходимые параметры запроса; исходный Excel и обучающие описания не используются как подсказки.

Подробные маршруты, JSON и коды ошибок: [server/API.md](server/API.md). Ключ платформы (`FORTE_API_KEY`) независим от ключа внешней модели.

## Конфигурация

См. [.env.example](.env.example). После изменения перезапустите сервер.

| Переменная | Назначение |
| --- | --- |
| `HOST`, `PORT` | По умолчанию созданная конфигурация использует `127.0.0.1:3001` |
| `FORTE_API_KEY` | Случайный приватный ключ API платформы |
| `LOCAL_AUTO_SESSION` | Автоматический вход разрешён только на loopback |
| `DATA_DIR` | Каталог SQLite, видео, временных файлов и результатов |
| `MAX_UPLOAD_MB` | Лимит видео; автоматически созданная конфигурация — 100 МБ |
| `MAX_ARCHIVE_MB` | Лимит ZIP, по умолчанию 500 МБ |
| `MAX_ARCHIVE_FILES` | До 100 файлов в архиве |
| `MAX_ARCHIVE_EXPANDED_MB` | До 2048 МБ после распаковки |
| `MAX_STORAGE_MB` | Общий лимит хранилища, 4096 МБ |
| `RETENTION_DAYS` | Срок хранения, 7 дней |
| `JOB_TIMEOUT_MS` | Максимальное время задания, до 1260000 мс |
| `MAX_CONCURRENT_JOBS`, `MAX_PENDING_JOBS` | Параллельные задачи и очередь |
| `FORTE_FFPROBE_PATH`, `FORTE_FFMPEG_PATH` | Пути к инструментам обработки видео |
| `PUBLIC_ORIGIN` | Точный HTTPS origin при публикации через TLS reverse proxy |

В режиме исходного кода FFprobe поставляется пакетом `ffprobe-static`; FFmpeg должен быть доступен в PATH или задан явно. В готовых установщиках оба инструмента включены. Воспроизведение MOV зависит от кодека и возможностей Chromium; автоматическое перекодирование не выполняется.

## Веб-развёртывание

По умолчанию сервер доступен только этому компьютеру. Для размещения в сети задайте `HOST`, точный HTTPS `PUBLIC_ORIGIN`, отключите `LOCAL_AUTO_SESSION` и используйте TLS reverse proxy. Пользователи входят ключом платформы. Не открывайте автоматически авторизованный loopback-сервис в Интернет через туннель.

Это общее рабочее пространство без SSO, ролей и изоляции записей по сотрудникам. Промышленный банковский запуск требует отдельной настройки доступа, хранения и аудита. Электронная оболочка сама по себе не создаёт публичный Web interface URL для жюри.

## Исходники

`app/` — интерфейс; `server/` — API и хранение; `tests/server/` — интеграционные проверки; `public/` — локальные ресурсы; `data/regulatory-sources.json` — публичный каталог нормативных источников. Остальное содержимое `data/` создаётся во время работы и исключено из Git.
