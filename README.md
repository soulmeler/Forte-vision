# Vision Forte

Платформа проверки кассовых операций по видеозаписям. Работает в браузере и как приложение Electron для macOS и Windows. Анализ выполняет модель на отдельном сервере команды или банка, подключённая по адресу API и ключу.

## Установка приложения

Готовые установщики находятся в [GitHub Releases](https://github.com/soulmeler/Forte-vision/releases).

- **macOS, Apple Silicon (M1–M4 и новее):** `Vision-Forte-2.0.0-mac-arm64.dmg`. Откройте DMG и перенесите Vision Forte в Applications.
- **macOS, Intel:** `Vision-Forte-2.0.0-mac-x64.dmg`, если эта сборка опубликована в релизе.
- **Windows 10/11, x64:** `Vision-Forte-2.0.0-win-x64.exe`. Запустите мастер установки; права администратора не требуются.

Установщик содержит актуальную платформу, встроенную среду Node.js, FFmpeg и FFprobe. Python, npm, видеокарта и веса модели на компьютере сотрудника не требуются. Для анализа нужен доступ к вашему серверу модели.

Сборки не подписаны сертификатами разработчика Apple/Microsoft; macOS и Windows могут показать предупреждение о неизвестном издателе. В репозитории нет сертификатов подписи. Для корпоративного распространения нужны подпись и нотарификация macOS.

## Подключение и работа

1. Запустите Vision Forte и откройте **«Сервер модели» → «Настроить API»**.
2. Введите адрес своего API и ключ. Для синхронного API используйте полный адрес вида `https://model.example/v1/analyze-video`.
3. Дождитесь готовности сервера. Выберите MOV/MP4 и нажмите **«Проверить видео»**.
4. Просмотрите вердикт, описание событий, таймкоды и кадры. Нормативные основания доступны в отдельном разделе.
5. Для нескольких записей нажмите **«Загрузить архив»**, выберите ZIP и подтвердите предупреждение о времени обработки. Результаты каждого видео появятся в списке справа. Кнопка **«Скачать Excel»** выгружает итоговую или промежуточную таблицу `.xlsx`.

Лимиты установленных приложений: 100 МБ на видео, 500 МБ на ZIP, до 100 файлов, до 2048 МБ после распаковки, 4096 МБ локального хранилища. Очередь проверяет видео последовательно. Необработанные файлы и ошибки явно отмечаются, а не превращаются в результат «нарушений нет».

API-ключ модели хранится только в памяти служебного процесса. После полного выхода из приложения введите подключение заново. Веса модели не включены; репозиторий и установщики не подтверждают качество её распознавания. Демо помечено как синтетическое и не анализирует загруженные записи.

## Где хранятся записи

- macOS: `~/Library/Application Support/Vision Forte/storage/`
- Windows: `%APPDATA%/Vision Forte/storage/`

Видео, очередь и результаты сохраняются локально. При запуске анализа выбранное видео передаётся указанному вами серверу модели. По умолчанию срок хранения — 7 дней. Удаление Windows-приложения сохраняет пользовательские данные.

## Запуск исходного кода

Нужен Node.js **22.13+**, рекомендуется Node.js 24 LTS, и npm. Команды выполняются из корня репозитория:

```sh
npm run setup
npm run build
npm start
```

Откройте `http://127.0.0.1:3001`. Первый запуск создаст приватный `platform/.env` со случайным ключом платформы. Ключ платформы и ключ внешней модели — разные ключи.

Electron из исходников:

```sh
npm run electron
```

Для разработки интерфейса: `npm run dev`. Настройки, контракт API и развёртывание веб-версии описаны в [документации платформы](platform/README.md) и [API](platform/server/API.md).

## Сборка установщиков

```sh
npm run setup
npm run dist:mac        # macOS Apple Silicon, выполнять на Mac
npm run dist:mac:intel  # macOS Intel, выполнять на Mac
npm run dist:win        # Windows x64, предпочтительно выполнять на Windows
```

Файлы появятся в `desktop/release/`. Скрипт собирает React, создаёт чистую среду с серверными зависимостями и добавляет FFmpeg/FFprobe для выбранной архитектуры. Приватная конфигурация рабочего проекта при сборке не копируется.

Workflow [desktop-release.yml](.github/workflows/desktop-release.yml) собирает macOS и Windows на отдельных системах. Запустите его вручную для артефактов или отправьте тег `v2.0.0` для GitHub Release. Публикация из локальной команды сборки отключена; загрузка в релиз выполняется отдельно.

## Проверки и ключи

```sh
npm test
npm run test:desktop
npm run scan:secrets
npm --prefix platform audit --omit=dev
```

Проверки охватывают загрузки, авторизацию, очередь, ZIP, Excel, ответы удалённого сервера, ошибки и автономный процесс приложения. Синтетические тесты проверяют платформу; точность модели необходимо измерять отдельно на видео, не участвовавших в обучении.

Секреты, `.env`, записи, SQLite, исходный Excel, обучающие материалы и локальные отчёты исключены из Git и установщиков. В примерах используются только заглушки. Собственный сканер проверяет распространённые форматы ключей и совпадения с локальными секретами; он не заменяет полноценную проверку безопасности. См. [SECURITY.md](SECURITY.md).

## Структура

```text
platform/app/           React-интерфейс, просмотр и результаты
platform/server/        Express API, SQLite, очередь, архивы, Excel
platform/public/        локальные шрифты, логотипы и иллюстрации
platform/tests/         интеграционные тесты
platform/data/regulatory-sources.json  каталог нормативных источников
platform/scripts/       запуск и приватная конфигурация
desktop/electron/      окно Electron и автономный процесс
desktop/scripts/       подготовка runtime и установщиков
desktop/runtime-deps/  зафиксированные серверные зависимости установщиков
scripts/               проверка секретов
.github/workflows/      CI, сборка и публикация
```

Старый HTML-прототип в `desktop/ui/` сохранён как исторический исходник и не включается в актуальные установщики. Исходные банковские видео, Excel и веса модели в публичный репозиторий не входят.

Интерфейс использует фирменные материалы Forte и локальные шрифты с лицензиями в `platform/public/fonts/`. Лицензии включённых FFmpeg/FFprobe и зависимостей сохраняются в ресурсах установленного приложения. Права на товарные знаки принадлежат их владельцам.
