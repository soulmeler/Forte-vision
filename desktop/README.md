# Vision Forte — Electron

Актуальное приложение открывает интерфейс из `platform/`. При разработке оно использует локальный сервис проекта; установленная версия запускает собственный сервис на свободном порту и хранит записи в пользовательском профиле.

Из корня проекта:

```sh
npm run setup
npm run build
npm run electron
npm run dist:mac
npm run dist:mac:intel
npm run dist:win
```

Установщики находятся в `desktop/release/`. Node.js, FFmpeg и FFprobe включены в установленные приложения; внешний сервер модели подключается отдельно через интерфейс. Ключей, датасета, видео и весов модели в сборке нет.

`electron/platform.cjs` — окно и жизненный цикл; `electron/runtime.cjs` — встроенный сервер. `scripts/prepare-runtime.mjs` подготавливает чистые ресурсы выбранной архитектуры; `scripts/distribute.mjs` вызывает electron-builder. Серверные зависимости фиксируются в `runtime-deps/package-lock.json`.

`electron/main.cjs`, `preload.cjs` и `ui/` относятся к старому HTML-прототипу. Они не являются точкой входа и не включаются в установщик.

macOS-сборки подписываются ad-hoc; сертификат Developer ID и нотарификация Apple не настроены. Подпись приложения и вложенных бинарных файлов проверяется после сборки. Windows-сборки не подписаны сертификатом разработчика. Windows-установщик NSIS предназначен для x64 и устанавливается в профиль пользователя. Приложение удаляется стандартным способом; пользовательские записи сохраняются.

Подробности установки, подключения API, проверки и публикации: [основной README](../README.md).
