# Данные и ключи

- Не добавляйте API-ключи, токены GitHub, сертификаты, `.env`, пользовательские записи, результаты анализа или исходный Excel в Git.
- Установленная платформа запускается на `127.0.0.1`, использует свободный порт и случайный ключ сессии. Ключ не включён в установщик.
- Ключ удалённой модели вводится в интерфейсе, хранится в памяти серверного процесса и не возвращается в API-ответах. После выхода подключение требуется настроить повторно.
- Запросы к модели не следуют HTTP-редиректам. Для удалённого подключения используйте HTTPS и свой доверенный сервер.
- Записи и SQLite хранятся в профиле пользователя. При анализе выбранное видео отправляется выбранному серверу. Доступ к профилю ОС даёт доступ к этим данным.
- ZIP проверяются на выход за каталог, символические ссылки, шифрование, CRC и лимиты распаковки.
- `npm run scan:secrets` проверяет отслеживаемые файлы; `node scripts/scan-secrets.mjs --staged` — содержимое индекса перед коммитом. Локальные `.env` используются только для поиска совпадений, значения не выводятся.
- Если реальный ключ оказался в коммите или публичной переписке, отзовите его на сервере и выдайте новый. Удаление строки из текущего файла не удаляет её из истории Git.

Это прототип общего рабочего пространства, без банковского SSO, ролей сотрудников и изоляции данных по пользователям. До промышленного внедрения нужны аудит, контроль доступа, шифрование хранилища, подпись приложений и проверка качества модели.

Не публикуйте действующие ключи и персональные банковские материалы в GitHub Issues. При сообщении об ошибке используйте обезличенные примеры.
